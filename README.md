# رسائلي — تطبيق مراسلة خاص (PWA + Supabase + GitHub Pages)

تطبيق مراسلة فورية بواجهة عربية RTL، يُثبَّت على iPhone من Safari، ويعمل على الخطة المجانية فقط.

> **ملاحظة معمارية مهمة:** المراسلة بين شخصين تحتاج خادماً مشتركاً، لذلك تُحفظ الحسابات والرسائل والوسائط في **Supabase** (كما طلبت). وتُحفظ نسخة من محادثاتك على جهازك في **IndexedDB** ليعمل التطبيق دون إنترنت. بياناتك لا تُرفع إلى GitHub أبداً؛ GitHub يستضيف ملفات التطبيق فقط. عزل المحادثات يتم عبر سياسات RLS داخل قاعدة البيانات: لا يستطيع أحد غير طرفي المحادثة قراءتها.

## 1) وظيفة كل ملف

| الملف | وظيفته |
|---|---|
| `index.html` | هيكل التطبيق (الشاشات) وروابط الـ manifest والأيقونات |
| `manifest.webmanifest` | تعريف التطبيق: الاسم، standalone، الألوان، الأيقونات |
| `sw.js` | Service Worker: تخزين ملفات التطبيق للعمل دون إنترنت + التحديث + استقبال الإشعارات |

| `css/app.css` | كل التصميم (RTL، المساحات الآمنة لـ iPhone، الوضع الليلي) |
| `js/config.js` | **الملف الوحيد الذي تعدّله:** رابط Supabase والمفتاح العام ومفتاح الإشعارات |
| `js/app.js` | نقطة التشغيل: التنقل، الجلسة، التحديث، الاتصال/الانقطاع |
| `js/api.js` | كل الاتصال بـ Supabase (حسابات، رسائل، تخزين، realtime) |
| `js/state.js` | حالة التطبيق والمزامنة وصندوق الصادر (منع التكرار) والإيصالات |

| `js/auth.js` | شاشات الدخول/التسجيل/الاستعادة/تأكيد البريد |
| `js/list.js` | قائمة المحادثات والطلبات وإضافة شخص |
| `js/chat.js` | شاشة المحادثة: نص، صور، فيديو، صوت، حذف، معرض الصور |

| `js/media.js` | ضغط الصور، التسجيل الصوتي، تخزين الوسائط محلياً |
| `js/backup.js` | تصدير/استيراد JSON (مع checksum) وتصدير CSV |
| `js/push.js` | اشتراك الإشعارات (Web Push) |
| `js/ui.js` `js/util.js` `js/icons.js` `js/nav.js` | مكوّنات الواجهة، دوال مساعدة، الأيقونات، وصلة التنقل |
| `supabase/schema.sql` | الجداول وسياسات الأمان (RLS) والتخزين — يُنفَّذ مرة واحدة |
| `supabase/push_trigger.sql` | (اختياري) يشغّل الإشعارات عند وصول رسالة |
| `supabase/functions/send-push/index.ts` | (اختياري) دالة إرسال الإشعارات |
| `vapid.html` | (اختياري) صفحة تولّد مفاتيح الإشعارات داخل متصفحك |
| `tests/` | الاختبارات الآلية (لا تحتاج رفعها إلى GitHub) |

## 2) إعداد Supabase (من iPhone، مجاناً)

1. افتح **supabase.com** في Safari ← Sign up ← **New project** (اختر الخطة **Free**، لا تُدخل بطاقة).
2. **SQL Editor** ← New query ← الصق كامل محتوى `supabase/schema.sql` ← **Run**.
3. **Project Settings → API**: انسخ **Project URL** و **anon public key** (أو Publishable key).
4. **Authentication → URL Configuration**: ضع في **Site URL** رابط تطبيقك على GitHub Pages (تحصل عليه في القسم 4، مثل `https://USERNAME.github.io/risa2li/`) وأضفه أيضاً في **Redirect URLs**. *(مهم لروابط التأكيد واستعادة كلمة المرور.)*
5. **Authentication → Providers → Email**: اترك «Confirm email» مفعّلاً (التحقق من البريد). 
   - ⚠️ خدمة البريد المجانية المدمجة في Supabase محدودة جداً (بضع رسائل في الساعة). تكفي لحسابين أو ثلاثة. إن واجهت «تجاوز الحد» انتظر ساعة، أو أوقف «Confirm email» مؤقتاً.
6. افتح `js/config.js` (على GitHub بعد الرفع) وضع `SUPABASE_URL` و `SUPABASE_ANON_KEY`. هذان المفتاحان عامّان وآمنان للنشر. **لا تضع أبداً service_role.**

## 3) رفع المشروع إلى GitHub من iPhone فقط

1. ثبّت من App Store تطبيق **Files** (موجود)، واحفظ ملف الـ ZIP فيه ثم **اضغط عليه مطولاً ← Uncompress** (فك الضغط).
2. افتح **github.com** في Safari ← سجّل الدخول ← **+ ← New repository**: الاسم `risa2li` ← **Public** ← Create.
3. في صفحة المستودع الفارغ اضغط **uploading an existing file**.
4. اضغط **choose your files** ← **Browse** ← اختر مجلد المشروع المفكوك (اختر الملفات والمجلدات: `index.html`, `sw.js`, `manifest.webmanifest`, الأيقونات، `css`, `js`, `supabase`, `vapid.html`، ...).
   - إن لم يسمح iOS برفع المجلدات دفعة واحدة، ارفع الملفات الجذرية أولاً، ثم أنشئ المجلدات بـ **Add file → Create new file** واكتب اسم الملف مع المسار مثل `js/app.js` والصق المحتوى، أو ارفع محتوى كل مجلد على حدة من داخل المجلد نفسه (الاسم `js/…` يُنشئ المجلد تلقائياً عند الرفع من صفحة المجلد).
   - **تأكد أن `index.html` في جذر المستودع** وليس داخل مجلد.
5. اكتب رسالة (Commit) ← **Commit changes** (على الفرع `main`).
6. عدّل `js/config.js` مباشرة على GitHub: افتحه ← أيقونة القلم ✏️ ← ضع القيم ← **Commit changes**.

## 4) تفعيل GitHub Pages

**Settings → Pages → Build and deployment**
- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)** ← **Save**

بعد دقيقة أو دقيقتين يظهر الرابط أعلى الصفحة: `https://USERNAME.github.io/risa2li/` (HTTPS تلقائياً). ضعه في Supabase كما في الخطوة 2-4.

## 5) التثبيت على iPhone

1. افتح الرابط في **Safari** (وليس Chrome) وانتظر حتى يظهر التطبيق.
2. اضغط زر **المشاركة** ⬆️.
3. **Add to Home Screen** (إضافة إلى الشاشة الرئيسية).
4. فعّل **Open as Web App** إن ظهر.
5. **Add**.
6. افتح التطبيق من الأيقونة على الشاشة الرئيسية، أنشئ حسابك، وأكّد بريدك من الرسالة.
7. جرّب العمل دون إنترنت: بعد فتحه مرة واحدة بالإنترنت، فعّل وضع الطيران وافتحه: ستظهر محادثاتك المحفوظة، وما تكتبه يُرسل تلقائياً عند عودة الاتصال.

**لدعوة الشخص الآخر:** أرسل له الرابط ليثبّته ويُنشئ حساباً. ثم من تطبيقك: ➕ ← اكتب بريده ← إرسال الطلب. عندما يقبل تظهر المحادثة عند الطرفين.

> ملاحظة iOS: رابط تأكيد البريد/استعادة كلمة المرور يفتح في Safari. بعد التأكيد ارجع إلى التطبيق على الشاشة الرئيسية وسجّل الدخول.

## 6) الإشعارات (اختياري — تحتاج إعداداً إضافياً)

إشعارات Web Push على iPhone تعمل فقط: iOS 16.4 أو أحدث، والتطبيق **مضاف إلى الشاشة الرئيسية** ومفتوح منها، ويُمنح الإذن عند الضغط على «تفعيل». وتحتاج جزءاً خادمياً مجانياً:

1. افتح `https://رابطك/vapid.html` ← ولّد المفاتيح. ضع **المفتاح العام** في `js/config.js` (`VAPID_PUBLIC_KEY`)، واحتفظ بالخاص سراً.
2. Supabase ← **Edge Functions** ← أنشئ دالة باسم `send-push` والصق `supabase/functions/send-push/index.ts` ← عطّل **Verify JWT** ← Deploy.
3. **Edge Functions → Secrets**: أضف `VAPID_PUBLIC_KEY` و `VAPID_PRIVATE_KEY` و `VAPID_SUBJECT` (مثل `mailto:you@example.com`) و `WEBHOOK_SECRET` (كلمة سرية طويلة).
4. في `supabase/push_trigger.sql` بدّل `PROJECT_REF` و `WEBHOOK_SECRET` ثم شغّله في SQL Editor.
5. في التطبيق: الإعدادات ← تفعيل الإشعارات.

محتوى الإشعار: اسم المرسل ومعاينة قصيرة للرسالة.

## 7) النسخ الاحتياطي والاستعادة

**الإعدادات ← النسخ الاحتياطي**
- **تصدير JSON:** ملف يحوي المحادثات والرسائل (بدون كلمات المرور وبدون ملفات الوسائط) مع **checksum** للتحقق من السلامة. على iPhone تظهر قائمة المشاركة: اختر **Save to Files** (حفظ في الملفات) وضعه في iCloud Drive إن شئت.
- **تصدير CSV:** للرسائل بترميز UTF-8 يفتح بالعربية في Excel/Numbers.
- **استعادة:** يتحقق من صحة الملف وأنه يخص حسابك، ويعرض ملخصاً ويطلب تأكيدك، ثم **يضيف** الرسائل المفقودة إلى جهازك فقط (لا يحذف ولا يستبدل شيئاً، ولا يرفع شيئاً للخادم).

**حدود يجب معرفتها (بلا مبالغة):**
- المتصفح **لا يستطيع** رفع نسخ احتياطية تلقائياً إلى iCloud Drive؛ الحفظ يدوي عبر تطبيق «الملفات». الكود مفصول في `js/backup.js` بحيث يمكن إضافة مزوّد نسخ دوري مستقبلاً (يحتاج تكاملاً مع واجهة iCloud/خدمة أخرى وإذن صريح).
- حذف بيانات Safari أو فقدان الجهاز قد يحذف **النسخة المحلية**؛ المحادثات نفسها محفوظة في Supabase وتعود عند تسجيل الدخول. ولا شيء يضمن عدم فقدان البيانات بنسبة 100%؛ لذلك صدّر نسخة بين الحين والآخر.
- ملفات الصور/الفيديو/الصوت محفوظة في Supabase وتُخزَّن مؤقتاً على الجهاز (حد 150MB) ولا تدخل في النسخة الاحتياطية.

## 8) حدود الخطة المجانية (مراعاة التخزين ونقل البيانات)

- التخزين 1GB ونقل 5GB/شهر تقريباً (قد تتغير شروط Supabase؛ راجع صفحة Pricing). لذلك: تُضغط الصور تلقائياً (أقصى 1600px)، والفيديو محدود بـ **45MB**، والصوت يُسجَّل بصيغة مضغوطة.
- حذف رسالة أو محادثة يحذف ملفاتها من التخزين لتوفير المساحة.
- مشاريع Supabase المجانية **تُوقَف عند عدم الاستخدام أسبوعاً**؛ إن حدث ذلك اضغط Restore في لوحة Supabase.
- لا توجد أي خدمة مدفوعة تُفعَّل تلقائياً. لا تنقر على Upgrade.

## 9) تحديث التطبيق

ارفع الملفات المعدّلة إلى GitHub وغيّر `const VERSION` في `sw.js` (مثل `v1.0.1`). عند فتح التطبيق يظهر إشعار «يتوفر تحديث للتطبيق ← تحديث الآن». المحادثات والبيانات المحلية لا تتأثر، وتتم ترقية هيكل IndexedDB تلقائياً (migrations) في `js/db.js`.

## 10) الأمان

- كلمات المرور تُدار بالكامل من Supabase Auth (لا تُخزَّن في التطبيق ولا في النسخ الاحتياطية).
- RLS: لا يقرأ المحادثة إلا طرفاها؛ البحث عن المستخدمين بالبريد **مطابقة تامة** فقط (لا قوائم).
- الوسائط في حاوية خاصة (Private) وتُعرض بروابط موقّعة مؤقتة؛ الصور الشخصية فقط في حاوية عامة بأسماء غير قابلة للتخمين.
- المحادثات غير مشفّرة طرفاً لطرف: مالك مشروع Supabase (أنت) تقنياً يستطيع الاطلاع على القاعدة. 

## 11) تشغيل الاختبارات (اختياري)

```
node tests/run.mjs
```
تستخدم Chromium (Playwright) وخادم Supabase وهمياً `tests/fake-supabase.js`.
